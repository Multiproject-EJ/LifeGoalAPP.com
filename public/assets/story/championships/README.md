# Championship ceremony art

Generated on 2026-07-28 with the built-in ImageGen workflow. The existing
white-and-blue PA mascot and builder-robot family concept were supplied as
identity and style references. Titles remain live HTML/CSS rather than being
baked into the raster art.

Each ceremony has two deliberately different compositions:

- `opening-ceremony.webp` is a wide Arena banner.
- `opening-ceremony-portrait.webp` is a purpose-authored 9:16 Story Mode
  micro-film frame. It must never be replaced with an automatic crop of the
  banner.

## First Circuit Championship

- Asset: `first-circuit/opening-ceremony.webp`
- Portrait micro-film: `first-circuit/opening-ceremony-portrait.webp`
- Runtime use: Island 30 Arena banner and First Circuit Story Mode manifest.
- Final prompt direction: a sunrise floating garden Arena where builder robots
  release weightless ribbons that unexpectedly become living constellation
  creatures; the PA wears a ceremonial glassworker visor and diplomatic sash;
  premium cinematic 3D mobile-game key art; joyful, warm and non-combatant; no
  text, logos, watermark, or generic trophy composition.
- Portrait direction: true 9:16 phone composition with the PA and builders in
  the lower foreground, ribbons spiralling through the centre, and the living
  constellation reveal blooming into the upper sky; one readable
  transformation beat with caption-safe space.

- Runtime files: approximately 0.42–0.47 MB each.
- Portrait source generation size: 941 × 1672 PNG.
- Portrait runtime format: lossy WebP, quality 88.
- Keep title copy, super-level labels, and buttons in app code for localization,
