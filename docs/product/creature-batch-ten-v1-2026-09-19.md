## Authoritative style correction

The user's latest clarification supersedes the earlier blanket clay preference:

**Card image = realistic, cinematic, dramatic. 3D figure = rounded clay interpretation.**

Identity is invariant: body plan, silhouette landmarks, colour placement, attention anatomy, emotional direction and intended pose. Rendering/material can differ. A painted or cinematic card can reveal a clay figure. Exact pose registration must be checked against an actual model later; generated paired images alone do not establish pixel-perfect pop-out continuity.

Prompts use the independent family briefs, not Pokémon art or character references. The legacy animal names do not prescribe real-animal anatomy. Mature eyes must not collapse into one baby-face template; form 1 may use softer larger eyes.

## Originality screen — limited, not clearance

The designs were generated independently from the project's own briefs. None was intentionally copied from Pokémon. This does **not** guarantee exhaustive uniqueness against every published character. Primary-source page access and image search were attempted; some official image endpoints could not be fetched and the first image search was rate-limited.

Reference shortlist:
- [Stonjourner official description and reference page](https://swordshield.pokemon.com/en-us/pokemon-galar-region/stonjourner/): an articulated stone body with arms and long legs. Cinder's broad continuous three-contact living arch and Prism's three joined walls use different construction. The shared architectural motif still warrants comparison before release.
- [Lunatone official Pokédex](https://www.pokemon.com/us/pokedex/lunatone): page access returned only an iframe, so not treated as a completed official visual check. Search-reference imagery establishes the obvious crescent-moon comparison to revisit for Celest. Its separate off-centre core, uneven attention openings, ground contact and broken surrounding frame are deliberate differentiators.
- [Trevenant official Pokédex](https://www.pokemon.com/es/pokedex/trevenant): page/image access was incomplete. Dreamroot's broad suspended canopy and low hanging core avoid an ordinary humanoid tree configuration, but botanical motifs are common and still require visual review.
- [Lunatone/Solrock visual reference surfaced in search](https://www.space.com/entertainment/its-pokemon-day-here-are-ten-pokemon-from-space-to-celebrate-the-iconic-series): used only as a comparison pointer, never a generation input.

Do not mark an asset “Pokémon-cleared.” The gallery explicitly keeps originality review open. Review shape, attention anatomy and characteristic colour placement together, not merely a changed texture or palette.
