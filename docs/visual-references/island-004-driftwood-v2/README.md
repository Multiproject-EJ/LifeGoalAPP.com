## Selected direction

Upgrade the same existing purple island. Preserve the five building locations and recognizable silhouettes. Purple remains strongest on the central Citadel and banners; Coral Cradle uses coral, Tidekeeper Hall uses teal, Pearl Archive uses terracotta/copper, and Concord Event Arena uses teal/coral/gold. Add richer gardens, materials, supported architecture, readable interiors, closer construction framing, and a visibly festive arena without moving or obstructing the board.

## Gameplay boundary

Island 004's signature mission remains **Raise the Broken Causeway**: six Masonry Sparks raise three spans, two sparks per span. The Event Arena landmark separately launches the active timed-event minigame selector. Island 001 introduces the first Event Arena; Island 004 mission completion unlocks the Vault Island gift.
