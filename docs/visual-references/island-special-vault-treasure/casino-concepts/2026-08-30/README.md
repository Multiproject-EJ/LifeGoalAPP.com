# Vault Casino concept packet

Visual direction for pooling five inspectable casino machines into the existing
Vault Palace atrium and museum architecture.

- `vault-casino-transforming-room-v1.png`: shared circular room and five machines.
- `vault-casino-five-game-icons-v1.png`: icon-family direction in reading order:
  Vault Rush, Crown Dice, Solar Orrery, Prism Cascade, Treasury Organ.

The machines are inspectable from Vault Island, but playable only when the
canonical Island Run loop grants an available Vault game. No ticket purchase or
microtransaction route is part of this concept.

## Implemented QA views

The `qa/` folder contains phone-frame captures for all five machines, the
inspect-only availability state, and the completed five-seal coffer. These are
runtime screenshots from `/dev/vault-casino-lab`, not generated concept art.
The final ceremony capture is `qa/vault-casino-grand-coffer-phone.png`.
