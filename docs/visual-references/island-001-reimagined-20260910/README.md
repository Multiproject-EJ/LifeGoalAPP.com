# Island 001 — new art direction proposals

User requested a massive visual upgrade to the whole island and all landmarks, using generated images to explore changed designs. Eivind approved all three images as the Island 001 V2 visual goals on 2026-09-10 and explicitly requested committing them and upgrading the island. They are visual goals, not implemented game screenshots.

Direction: sculpted ocean-rooted terrain, purposeful gardens, distinct landmark silhouettes, civic ivory/brass/blue material language, and an impressive subterranean diplomatic Assembly. Preserve the four landmark functions, central excavation, live circular route and integrated lift idea. The accepted 3 + 5 + 2 progression remains unchanged.

Generated with the built-in image generation tool. Exact prompts are saved alongside the images. Generated layout and hidden geometry must be reconciled with the canonical board and footprint contract before implementation. Do not silently treat invented structures or image-drawn paths as gameplay authority.

Delivered images: `01-island-overview.png`, `02-landmark-studies.png`, `03-assembly-chamber.png`. The landmark sheet is top-left Hatchery, top-right Habit Oak, bottom-left Wisdom Archive, bottom-right Observatory. Exact prompts use matching `.prompt.txt` names; hashes and reference relationships are in `manifest.v1.json`. Existing local procedural work is the V1 baseline for the V2 reconstruction.

Visual review: all four landmarks have distinct silhouettes and visible lift entries; the Assembly has desks, dais, interpreter galleries and four shafts. Images are intentionally ambitious. Foliage density, multi-wing footprints and tall chamber proportions are concept inventions that require a constrained production interpretation, not literal automatic import.
