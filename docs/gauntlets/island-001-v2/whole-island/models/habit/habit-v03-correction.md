# Habit Oak v03 canopy refinement

User requested more interesting, detailed greenery. The actual release-v2 frame showed broad flat green pads. The approved original has layered, irregular rich foliage with a fine leaf edge. V03 uses deeper irregular core envelopes, two offset connected lobes and ten closed folded leaf tips per crown, embedded in the foliage. Dark cores and varied olive/emerald tips give depth without a new material or texture cost. The exact 160-triangle budget per branch crown is redistributed; v02 used two 80-triangle envelopes.

All non-canopy geometry and the original random sequence are preserved. Ground gardens and cypress are unchanged. Fixed footprint, canonical socket and all additive stages remain controls. V01/V02 source and binaries remain immutable. This is a frozen candidate for actual browser review, not self-approved visual quality.
