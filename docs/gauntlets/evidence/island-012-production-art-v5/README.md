# Island 012 production art v5 — hinged reward chamber

Date: 2026-08-21

## Goal

Replace the Oasis Crown Citadel reward chamber's flower-like radial opening
with six glass panels that visibly peel backward from mechanical lower-rim
hinges.

## Before

- `../island-012-production-art-v4/overview-phone.png`
- All six spherical panels pivoted around the dome centre.
- The synchronized radial motion read as a lotus or flower opening.

## After

- `overview-phone-hinged-reward.png`
- `citadel-hinged-reward-motion-phone.png`
- `citadel-hinged-reward-open-phone.png`
- Each panel now has a pivot at the dome's lower rim, an offset shell, and a
  visible gold axle aligned to the local tangent.
- A restrained stagger lets the panels peel backward in sequence.
- The placeholder token remains explicitly presentation-only and does not own
  reward state or grant gameplay output.

  `PCFShadowMap`.
