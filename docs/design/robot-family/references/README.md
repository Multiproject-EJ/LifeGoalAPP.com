# HabitGame robot-family reference register

## Authority order

1. The original three-robot family concept supplied by Eivind defines the family language, role hierarchy, white shell construction, dark visors, luminous accents, and friendly proportions.
2. The four original Orby images below are authoritative for the Project Manager / PA. They establish Orby's dome as an active visual brain, the compact oblate body, circular fin hinges, recessed hover core, and clean rear shell.
3. The generated Heavy Worker and Mini Artist sheets are reconstruction aids for modelling hidden views. They are not final canon until Eivind approves their shapes.

## Generated reconstruction studies

### `heavy-worker-turnaround-v1.png`

Prompt intent: create a clean six-view orthographic modelling sheet for the Heavy Worker from the supplied family concept, preserving its broad white-and-gold shell, expressive visor, two load-bearing primary arms with open four-digit hands, twin overhead autonomous manipulators, rear utility hardpoints, and underside hover thruster. Neutral pose, consistent proportions and no perspective drama.

### `mini-artist-turnaround-v1.png`

Prompt intent: create a clean six-view orthographic modelling sheet for the Mini Job Robot / Artist from the supplied family concept, exactly half the Project Manager's uniform scale, with a cuter compact body, mint sensor cap, expressive visor, small articulated arms, brush/stylus and paint tray, rear tool cassette, and underside hover thruster. Neutral pose, consistent proportions and no perspective drama.

## Known uncertainty

- The Heavy Worker and Mini Artist rear/underside designs are informed inventions based on the family concept.
- The Project Manager rear and underside are strongly supported by the original Orby studies.
- Before production export, approve or revise the two generated sheets and create any required close-ups for sockets, hands and tool interfaces.
