# Island 018 Jungle Expedition - Projection Route Decision

Initial route: hybrid source-fidelity island build.

Use procedural Three.js geometry for the large runtime hierarchy: floating
cliff, temple terraces, stairs, rope bridges, landmark structures, vegetation
clusters, waterfall planes, lighting anchors and action-ready scene parts.

Use exact source crops as visual contracts and possible texture/albedo
references only after material-region evidence is created. Because the source
contains baked UI and non-runtime tile art, do not project the full source as a
runtime texture. If a painted backplate or focused billboard is later approved,
record it as secondary evidence and keep the live board, HUD and controls
separate.

Hidden sides are lower-confidence. Any generated side/back view, UI-free goal
image or construction turnaround must be copied into
`docs/visual-references/island-018-jungle-expedition/secondary-inferred/` with
a neighboring provenance sidecar and manifest hash before it informs code.
