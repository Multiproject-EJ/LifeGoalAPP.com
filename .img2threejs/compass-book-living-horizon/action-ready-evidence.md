# Living Horizon action-ready evidence

The production relief exposes a nested `sculptRuntime` hierarchy with:

- 28 stable selectable component entries covering the root, contact frame, four terrain systems, continuous path core/rails, sanctuary, workshop, gathering place, and horizon gate system;
- named sockets for the path origin and each semantic life zone;
- a shallow box collider intent for book-scene picking/physics integration;
- destruction groups for landscape, life zones, and horizon, retained as metadata only because the feature is presentation-only;
- independent animation anchors for the sun, ray fan, open gate leaves, gathering hearth, violet path emission, and amber emission;
- reduced-motion behavior that freezes decorative movement while retaining the complete model;
- all DOM text, answers, progress, controls, focus, and persistence outside the Three.js hierarchy.

This makes later Island Run completion/fill ceremonies additive presentation work. It does not create a gameplay write path or another content/state owner.
