# Expedition Ship reference suitability

Verdict: **conditional pass for macro transform blockout**.

The reference pack provides one strong frontal three-pose sheet, one docked/service exterior, two compact exterior/cutaway views, an interior adjacency sheet and a central-atrium view. This is sufficient to establish the controller-derived macro silhouette, protected garden, human scale, major deck zones and intended transformation states.

It is not sufficient for exact rear/top/belly reconstruction or manufacturing-grade clearance. Those regions remain explicitly inferred and must pass multi-angle self-consistency rather than reference likeness. Projection is inappropriate because the sources contain baked hangar lighting and because the surfaces move independently.

Proceed only under these conditions:

1. first pass is macro geometry and pivots only;
2. no room or deck may teleport, intersect another occupied volume, or rotate through the atrium;
3. the model stays at medium/large-office-building scale;
4. docked, expedition and flight poses use one scene graph;
5. rear/top/belly accuracy is not claimed until additional views exist;
6. front, side, rear, top and three-pose phone captures are mandatory before the macro rig can continue.

The user has explicitly approved beginning the 3D model from largest shapes first, with smaller details deferred until the macro transform behaves correctly.
